# Abbreviations & prosigns

Two related but **distinct** groups. Keep them separate.

- **Abbreviations** — shortened words/phrases sent as normal characters with
  normal spacing (`OM`, `ES`, `TNX`). Single meaning.
- **Prosigns** — two letters **run together as one symbol** (no inter-character
  gap) that act as punctuation/procedure signals (`AR`, `SK`, `KN`). Morse-specific.

Wikipedia lists **~100** abbreviations; we should curate a **common** subset, not
ship all of them.

## Prosigns (the standard ~10)

Written with an overbar in Morse literature (shown here as run-together).

| Prosign | Meaning |
|---|---|
| AR | End of message |
| SK (VA) | End of contact / end of work |
| KN | Over — named/specific station only (not an open call) |
| BT | Separator / "break" between text sections |
| AS | Wait / stand by |
| K | Invitation to transmit (any station) |
| CT (KA) | Start of transmission / attention |
| SN (VE) | Understood / verified |
| BK | Break-in (invite other station to interrupt) |
| HH (8 dots) | Error / correction |
